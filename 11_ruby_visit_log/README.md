# 11. Ruby — анализ журнала посещений из текстового файла

## Постановка задачи

Веб-сервер записывает каждое обращение к сайту строкой в журнал (лог). Нужно прочитать журнал и построить отчёт:
- общее число запросов, период, число уникальных посетителей (по IP-адресу), объём переданных данных;
- самые популярные страницы и самые активные посетители;
- посещения по дням и по часам суток (с текстовой гистограммой и пиковым часом);
- распределение **кодов ответа** HTTP (200 — успешно, 403 — доступ запрещён, 404 — страница не найдена, 500 — ошибка сервера);
- ошибочные запросы (коды ≥ 400) с указанием страниц и IP.

Каждая строка разбирается **регулярным выражением** (шаблоном, описывающим формат строки). Строки, не подходящие под формат, не прерывают работу — их номера выводятся в отчёте. Отчёт печатается и сохраняется в файл.

Группировки сделаны встроенными методами коллекций Ruby: `group_by` (разбить на группы по ключу), `sort_by`, `transform_values`, `sum` и т.д.

## Входные данные

`access.log` — 120 записей за два дня (плюс одна специально испорченная строка):

```
ДАТА       ВРЕМЯ    IP             МЕТОД СТРАНИЦА     КОД РАЗМЕР(байт)
2026-10-01 08:31:52 192.168.0.23   GET   /login       200 15205
2026-10-01 09:02:10 192.168.0.17   GET   /admin       403 0
```

(в файле поля разделены одним пробелом)

## Запуск
### Через Docker

Отчёт `report.txt` будет сохранён в текущей папке:

```bash
docker run --rm -it -e LANG=C.UTF-8 -v "$PWD":/app -w /app ruby:3.4-bookworm \
  ruby log_stats.rb access.log report.txt 5
```


Нужен Ruby 2.7+ (`sudo apt install ruby`).

```bash
ruby log_stats.rb access.log report.txt 5    # журнал, файл отчёта, размер топов (по умолчанию access.log, report.txt, 5)
```
