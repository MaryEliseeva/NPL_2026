# 15. Rust — клиент-серверная система для выполнения статистических запросов

## Постановка задачи

Сервер принимает по TCP запросы на вычисление статистических характеристик набора чисел и возвращает результат. Клиент отправляет запросы — интерактивно, одной командой или загрузив данные из файла. Одновременно могут работать несколько клиентов, у каждого свой набор данных.

Поддерживаемые характеристики:
- количество, сумма, среднее, минимум, максимум, размах;
- **медиана** (значение «посередине» отсортированного набора) и **перцентиль** p (значение, ниже которого лежит p % данных; между соседними элементами берётся линейная интерполяция);
- **мода** (самое частое значение; если все различны — моды нет);
- выборочная **дисперсия** (средний квадрат отклонения от среднего, делитель n−1) и **стандартное отклонение** (корень из дисперсии);
- **выбросы** по правилу межквартильного размаха: значения вне [Q1 − 1.5·IQR; Q3 + 1.5·IQR], где Q1, Q3 — 25-й и 75-й перцентили, IQR = Q3 − Q1;
- `SUMMARY` — всё сразу.

Устройство:
- `src/lib.rs` — статистические функции (с модульным тестом);
- `src/bin/server.rs` — сервер: `TcpListener` принимает подключения, на каждое запускается **поток** (`thread::spawn`). Общий для всех потоков счётчик запросов — `Arc<AtomicUsize>`: `Arc` позволяет нескольким потокам владеть одним объектом, `AtomicUsize` — число, которое можно безопасно увеличивать из разных потоков без блокировок;
- `src/bin/client.rs` — клиент.

Только стандартная библиотека, внешних зависимостей нет.

## Протокол

Одна строка — один запрос. Ответ начинается с `OK` или `ERR`; если первая строка ответа заканчивается двоеточием, ответ многострочный и завершается строкой `END`.

| Команда | Действие |
|---|---|
| `LOAD <числа>` / `ADD <числа>` | задать / дополнить набор данных клиента |
| `SHOW` / `CLEAR` | показать / очистить набор |
| `COUNT SUM MEAN MEDIAN MODE MIN MAX RANGE VAR STD OUTLIERS [числа]` | характеристика по числам из запроса, а если их нет — по набору |
| `PERCENTILE <0..100> [числа]` | перцентиль |
| `SUMMARY [числа]` | полная сводка |
| `HELP`, `QUIT` | справка, отключиться |

Дробные числа можно писать через точку или запятую.

## Входные данные

`data.txt` — 20 значений времени ответа сервиса в миллисекундах (среди них два явных выброса — 450 и 500). Строки с `#` — комментарии.

## Запуск
### Через Docker

Соберите клиент и сервер:

```bash
docker run --rm -it -v "$PWD":/app -w /app rust:1-bookworm \
  cargo build --release
```

В отдельном терминале запустите сервер на опубликованном порту:

```bash
docker run --rm -it -p 7878:7878 -v "$PWD":/app -w /app rust:1-bookworm \
  ./target/release/server 0.0.0.0:7878
```

Клиент подключается к серверу на хосте:

```bash
docker run --rm -it -v "$PWD":/app -w /app rust:1-bookworm \
  ./target/release/client host.docker.internal:7878 --file data.txt SUMMARY
```


Нужен Rust (rustup.rs).

```bash
cargo build --release

# терминал 1 — сервер (адрес по умолчанию 127.0.0.1:7878)
./target/release/server

# терминал 2 — клиент
./target/release/client --file data.txt SUMMARY      # загрузить файл и выполнить одну команду
./target/release/client MEAN 1 2 3,5                 # разовый запрос
./target/release/client                              # интерактивный режим
```

(То же через cargo: `cargo run --release --bin server`, `cargo run --release --bin client -- --file data.txt SUMMARY`.)

Тест статистических функций: `cargo test`.
