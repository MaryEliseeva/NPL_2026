# 1. Ada — параллельный анализ массива

## Постановка задачи

Сгенерировать целочисленный массив из N элементов и параллельно найти его минимум, максимум и среднее значение.

Массив делится на T равных участков, каждый участок обрабатывает отдельная **задача** (task — поток выполнения в Ada). Задача считает минимум, максимум и сумму своего участка и передаёт их в **защищённый объект** (protected object — объект, к которому одновременно может обращаться только одна задача, поэтому общие данные не портятся). Главная программа ждёт завершения всех задач и выводит итог. Для проверки тот же результат считается последовательно, выводится время обоих вариантов.

Границы участка задача получает через **рандеву** (rendezvous) — синхронную встречу двух задач: главная вызывает `Start`, задача принимает вызов в `accept Start`.

## Входные данные

Аргументы командной строки (необязательные):

| Аргумент | Смысл | По умолчанию |
|---|---|---|
| `N` | количество элементов | 10 000 000 |
| `T` | количество задач | 4 |

Массив заполняется случайными числами из диапазона [-1 000 000; 1 000 000] с фиксированным зерном, поэтому результат воспроизводим.

## Запуск

Нужен компилятор GNAT 
  ```bash  
  docker run --rm -it \

  -w /app \
  tomekw/ada-gnat:12.2.0 \
  bash
  ```

```bash
gnatmake -gnat2022 -O2 array_stats.adb
./array_stats 10000000 4
```
