# 8. Scheme — поиск наибольшей возрастающей подпоследовательности

## Постановка задачи

Дана последовательность чисел. **Подпоследовательность** — это элементы, взятые из неё с сохранением порядка, но не обязательно подряд. Нужно найти самую длинную строго возрастающую подпоследовательность (LIS — Longest Increasing Subsequence), её позиции в исходных данных и число различных подпоследовательностей такой же длины.

Пример: в `10 9 2 5 3 7 101 18 4 8 6 12` одна из самых длинных — `2 5 7 8 12` (длина 5).

Решение — **динамическое программирование** (задача разбивается на подзадачи, ответы на которые запоминаются в таблице и переиспользуются):

- `len[i]` — длина самой длинной возрастающей подпоследовательности, которая **заканчивается** элементом `a[i]`;
- `len[i] = 1 + max(len[j])` по всем `j < i`, у которых `a[j] < a[i]` (если таких нет — 1);
- `prev[i]` запоминает, из какого `j` пришли, — по этим ссылкам ответ восстанавливается с конца;
- `cnt[i]` — сколько различных подпоследовательностей длины `len[i]` заканчивается на `a[i]`.

Ответ — максимум из `len[i]`. Сложность O(n²).

## Входные данные

Три варианта:
- без аргументов — встроенный пример;
- числа прямо в аргументах командной строки;
- путь к файлу с числами через пробел/перевод строки (`numbers.txt`).

## Запуск
### Через Docker

```bash
docker run --rm -it -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 \
	-v "$PWD":/app -w /app debian:bookworm-slim sh -lc \
	'apt-get update && apt-get install -y --no-install-recommends guile-3.0 && guile lis.scm numbers.txt'
```

Переменные `LANG` и `LC_ALL` включают UTF-8 в контейнере; без них русские строки могут выводиться как `????`.


Нужен GNU Guile (`sudo apt install guile-3.0`).

```bash
guile lis.scm
guile lis.scm numbers.txt
guile lis.scm 3 1 4 1 5 9 2 6 5 3 5
```
