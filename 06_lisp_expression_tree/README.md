# 6. Lisp — рекурсивное вычисление выражения, представленного деревом

## Постановка задачи

Арифметическое выражение задано **деревом**: внутренний узел — операция, его дети — аргументы, листья — числа или имена переменных. В Лиспе такое дерево естественно записывается списком в **префиксной форме** (операция стоит перед аргументами):

```
(+ 2 (* 3 4))          ≡   2 + 3·4

        +
       / \
      2   *
         / \
        3   4
```

Нужно рекурсивно вычислить значение дерева собственной функцией (встроенный `eval` не используется):
- число → само число;
- переменная → её значение из таблицы переменных;
- список `(op a b ...)` → сначала рекурсивно вычислить все поддеревья, затем применить к результатам операцию `op`.

Поддерживаются операции `+ - * / ^ sqrt max min` (у `-` с одним аргументом — смена знака) и присваивание `(set имя выражение)`. Деление выполняется точно: `5/2` — это **рациональное число** (обыкновенная дробь), Лисп хранит его без округления. Ошибки (деление на ноль, неизвестная переменная или операция) перехватываются и выводятся, программа продолжает работу.

Для каждого выражения выводятся: исходное дерево, инфиксная запись, дерево с отступами и значением каждого поддерева, итоговый результат.

## Входные данные

Файл `expressions.txt` — выражения по одному (можно в несколько строк), комментарии начинаются с `;`:

```lisp
(+ 2 (* 3 4))
(set x 5)
(+ (^ x 2) (* -3 x) (- y))
(/ 1 (- x 5))        ; деление на ноль — будет сообщение об ошибке
```

## Запуск
### Через Docker

```bash
docker run --rm -it -v "$PWD":/app -w /app debian:bookworm-slim sh -lc \
  'apt-get update && apt-get install -y --no-install-recommends sbcl && sbcl --script expr.lisp expressions.txt'
```


Нужен SBCL (`sudo apt install sbcl`).

```bash
sbcl --script expr.lisp expressions.txt
```
