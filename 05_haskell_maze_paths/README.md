# 5. Haskell — рекурсивный поиск количества путей в лабиринте

## Постановка задачи

Лабиринт задан прямоугольной сеткой: стены `#`, проходы `.`, вход `S`, выход `E`. Ходить можно на соседнюю клетку вверх, вниз, влево и вправо. Нужно найти количество различных **простых путей** от `S` до `E` — путей, в которых ни одна клетка не посещается дважды.

Решение — рекурсивный **поиск с возвратом** (backtracking, перебор всех вариантов с откатом):

```
пути(p) = 1,  если p — выход
пути(p) = Σ пути(сосед) по непосещённым соседям, иначе
```

Множество посещённых клеток передаётся в рекурсию как аргумент (`Data.Set`), поэтому «откат» происходит сам собой — в Haskell данные неизменяемы, и каждая ветка рекурсии видит своё множество.

Дополнительно программа строит **ленивый** список самих путей (элементы списка вычисляются только по мере надобности) и рисует кратчайший и самый длинный путь звёздочками.

## Входные данные

Текстовый файл с лабиринтом, например `maze.txt`:

```
#########
#S..#...#
#.#.#.#.#
#.......#
#.#.#.#.#
#...#..E#
#########
```

`maze_small.txt` — маленький лабиринт с двумя путями для быстрой проверки. Число путей растёт экспоненциально, поэтому для больших открытых лабиринтов перебор будет долгим.

## Запуск
### Через Docker

```bash
docker run --rm -it -v "$PWD":/app -w /app haskell:9.14-bookworm \
	runghc Maze.hs maze.txt
```


Нужен GHC (`sudo apt install ghc`).

```bash
runghc Maze.hs maze.txt
# или скомпилировать:
ghc -O2 Maze.hs && ./Maze maze.txt
```

