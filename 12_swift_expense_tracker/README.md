# 12. Swift — трекер расходов

## Постановка задачи

Консольная программа для учёта личных расходов. Каждый расход — это дата, сумма, категория и описание. Возможности:

| Команда | Действие |
|---|---|
| `add <сумма> <категория> [описание] [--date ГГГГ-ММ-ДД]` | добавить расход (дата по умолчанию — сегодня) |
| `list [--category К] [--month ГГГГ-ММ]` | список расходов с фильтрами и итоговой суммой |
| `stats [--month ГГГГ-ММ]` | статистика: всего, среднее за день, крупнейшая трата, разбивка по категориям с долями и гистограммой, по месяцам |
| `delete <номер>` | удалить расход |
| `help`, `exit` | справка, выход |

Данные хранятся в **CSV-файле** (текстовая таблица: строки — записи, поля разделены символом `;`) и перезаписываются после каждого изменения. Сумму можно вводить и через точку, и через запятую. Некорректный ввод (отрицательная сумма, неверная дата) отклоняется с подсказкой.

Программа работает в двух режимах: разовая команда из аргументов командной строки или интерактивный режим (без аргументов) — команды вводятся в цикле.

Для группировки используется `Dictionary(grouping:by:)` — стандартный способ Swift разложить массив по словарю «ключ → массив элементов с этим ключом».

## Входные данные

`expenses.csv` — пример с 10 расходами за сентябрь–октябрь 2026. Если файла нет, он будет создан. Другой файл можно задать переменной окружения `EXPENSES_FILE`.

```
id;date;amount;category;note
1;2026-09-02;450.00;Транспорт;проездной
2;2026-09-03;1280.50;Продукты;Пятёрочка
```

## Запуск
### Через Docker

Скомпилируйте программу и запустите сводку по `expenses.csv`:

```bash
docker run --rm -it -v "$PWD":/app -w /app swift:6.2.4-bookworm sh -lc \
  'swiftc main.swift -o expenses && ./expenses stats'
```


Нужен Swift 5.5+ (swift.org; на macOS — вместе с Xcode).

```bash
swiftc main.swift -o expenses
./expenses stats
./expenses add 350 Кафе кофе и круассан
./expenses add 1999.90 Продукты закупка --date 2026-10-12
./expenses list --month 2026-10
./expenses delete 3
./expenses              # интерактивный режим
```

Без компиляции: `swift main.swift stats`.
