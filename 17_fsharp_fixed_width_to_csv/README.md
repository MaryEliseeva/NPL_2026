# 17. F# — конвертация таблицы фиксированной ширины в CSV

## Постановка задачи

В **таблице фиксированной ширины** каждый столбец занимает строго определённые позиции символов в строке, а значения дополнены пробелами до ширины столбца (так выглядят отчёты старых систем, банковские выгрузки, вывод консольных утилит). Нужно преобразовать такую таблицу в **CSV** (Comma-Separated Values — текстовая таблица, где поля разделены запятой).

Главная задача — найти границы столбцов. Программа делает это одним из трёх способов (в порядке приоритета):
1. **явно** — пользователь задаёт ширины столбцов: `--widths 6,14,6` (все, кроме последнего, — он читается до конца строки);
2. **по строке-разделителю** — если под заголовком стоит строка из дефисов (`---- -------- ------`), каждая группа дефисов задаёт столбец, сама строка в CSV не попадает;
3. **автоматически** — позиция, на которой во **всех** строках стоит пробел, считается промежутком между столбцами. Пробелы внутри значений («Bolt M6») не мешают, если в той же позиции в других строках стоит не пробел.

Значения обрезаются от пробелов. При записи соблюдаются правила экранирования CSV (стандарт RFC 4180): поле, содержащее разделитель, кавычку или перевод строки, берётся в кавычки, а кавычки внутри удваиваются (`Сидоров "Сид" Пётр` → `"Сидоров ""Сид"" Пётр"`). Пустые ячейки становятся пустыми полями. Табуляции заменяются на 4 пробела.

Программа пишет в поток ошибок, как были найдены столбцы и что в каждом из них, чтобы результат было легко проверить.

## Входные данные

- `employees.txt` — таблица сотрудников со строкой-разделителем, кириллицей, запятой и кавычками в значениях, пустой ячейкой;
- `stock.txt` — таблица без разделителя (для автоопределения и `--widths`).

```
ID   Сотрудник            Город            Оклад     Принят
---- -------------------- ---------------- --------- ----------
1    Иванов Иван          Санкт-Петербург  85000.50  2021-03-15
3    O'Brien, Patrick     Dublin           99000     2022-06-30
```

## Запуск
### Через Docker

Файл `employees.csv` будет создан в текущей папке:

```bash
docker run --rm -it -v "$PWD":/app -w /app mcr.microsoft.com/dotnet/sdk:8.0 \
  dotnet fsi convert.fsx employees.txt employees.csv
```


Нужен .NET SDK 6+ (в него входит F# Interactive — `dotnet fsi`).

```bash
dotnet fsi convert.fsx employees.txt employees.csv     # результат в файл
dotnet fsi convert.fsx stock.txt                        # результат в консоль
dotnet fsi convert.fsx stock.txt stock.csv --delimiter ";"
dotnet fsi convert.fsx stock.txt --widths 6,14,6
```
