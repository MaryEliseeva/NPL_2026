# 13. Erlang — TCP-сервер для хранения и выдачи заметок

## Постановка задачи

Написать сервер, к которому по протоколу **TCP** подключаются клиенты и работают с общим набором заметок: добавляют, просматривают, ищут и удаляют. Заметки сохраняются в файл и переживают перезапуск сервера. Несколько клиентов могут работать одновременно.

Устройство сервера — несколько **процессов Erlang** (лёгкие изолированные процессы виртуальной машины BEAM, общаются только сообщениями):
- `storage` — единственный процесс, владеющий заметками. Остальные процессы присылают ему запросы и ждут ответ. Раз данные трогает только он, одновременные запросы обрабатываются по очереди и не мешают друг другу — блокировки не нужны;
- `acceptor` — ждёт новые подключения (`gen_tcp:accept`) и на каждое запускает отдельный процесс;
- клиентский процесс — читает команды своего клиента построчно и отвечает.

## Протокол

Текстовый: одна команда — одна строка, ответ начинается с `OK` или `ERR`. Ответы-списки состоят из нескольких строк и заканчиваются строкой `END`.

| Команда | Ответ |
|---|---|
| `ADD <текст>` | `OK добавлена заметка N` |
| `LIST` | все заметки: `N. [дата] текст`, затем `END` |
| `GET <N>` | `OK дата \| текст` |
| `DEL <N>` | `OK заметка N удалена` |
| `FIND <слово>` | заметки, содержащие слово (без учёта регистра), затем `END` |
| `COUNT` | количество заметок |
| `HELP` / `QUIT` | список команд / отключиться |

Команды не чувствительны к регистру. Ошибки (нет заметки, номер не число, неизвестная команда) возвращаются как `ERR ...`, соединение не рвётся.

## Входные данные

Файл `notes.dat` создаётся автоматически рядом с сервером: одна заметка на строку, `номер⇥дата⇥текст`.

## Запуск
### Через Docker

Из папки проекта запустите сервер; `notes.dat` останется в этой папке:

```bash
docker run --rm -it -p 5555:5555 -v "$PWD":/app -w /app erlang:27 \
    sh -lc 'erlc notes_server.erl && exec erl -noshell -s notes_server start'
```

Подключитесь к серверу из другого терминала на хосте:

```bash
nc localhost 5555
```


Нужен Erlang/OTP 21+ (`sudo apt install erlang`).

```bash
erlc notes_server.erl
erl -noshell -s notes_server start          # порт 5555
erl -noshell -s notes_server start 6000     # другой порт
```

Клиент — любая программа для «сырого» TCP, например `nc` (netcat) или `telnet`. Можно открыть несколько терминалов и подключиться одновременно:

```bash
nc localhost 5555        # или: telnet localhost 5555
```

## Пример сессии

```
OK сервер заметок. HELP — список команд
ADD Купить молоко
OK добавлена заметка 1
ADD Купить хлеб
OK добавлена заметка 2
FIND хлеб
OK список:
2. [2026-10-14 18:24] Купить хлеб
END
GET abc
ERR номер должен быть числом
```

Лог сервера:

```
Загружено заметок: 0
Сервер заметок слушает порт 5555
[+] клиент 127.0.0.1:34274 подключился
    127.0.0.1:34274: ADD Купить молоко
```
