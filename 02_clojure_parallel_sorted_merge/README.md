# 2. Clojure — параллельное объединение отсортированных файлов

## Постановка задачи

Дано несколько текстовых файлов, в каждом — отсортированные по возрастанию целые числа, по одному на строку. Нужно объединить их в один отсортированный файл, выполняя слияние параллельно.

Алгоритм — попарное слияние «турнирной сеткой»: на каждом раунде списки разбиваются на пары, и все пары сливаются одновременно, каждая в своём потоке. Из K списков после раунда остаётся ⌈K/2⌉, и так до одного. Слияние двух отсортированных списков (merge) проходит оба списка одним проходом, каждый раз забирая меньший из текущих элементов — это работает за O(n + m).

Используемые средства Clojure:
- `future` — запускает выражение в отдельном потоке и возвращает «обещание» результата; `deref` ждёт результат;
- `pmap` — параллельный `map`, им файлы читаются одновременно.

Программа выводит, в каком потоке сливалась каждая пара, и проверяет, что результат отсортирован. Если какой-то входной файл не отсортирован, программа предупреждает и сортирует его сама.

## Входные данные

Папка `data/` — пять небольших файлов `a.txt` … `e.txt` (числа по одному на строку). Для проверки на больших объёмах можно сгенерировать файлы командой `--gen`.

## Запуск
### Через Docker

Запустите из папки проекта; `merged.txt` появится в этой же папке:

```bash
docker run --rm -it \
  -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 \
  -v "$PWD":/app -w /app \
  --entrypoint /bin/sh \
  clojure:tools-deps
```


Нужны Java и Clojure (`sudo apt install clojure` или официальный clojure CLI).

```bash
# Debian/Ubuntu-пакет clojure
clojure merge.clj merged.txt data/a.txt data/b.txt data/c.txt data/d.txt data/e.txt

# официальный clojure CLI (clojure.org) — то же самое через -M
clojure -M merge.clj merged.txt data/*.txt

# сгенерировать 8 файлов по 200 000 чисел в data/gen_XX.txt и слить их
clojure merge.clj --gen 8 200000
clojure merge.clj big.txt data/gen_*.txt
```
