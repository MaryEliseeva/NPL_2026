# 3. D — параллельный поиск простых чисел в диапазоне

## Постановка задачи

Найти все простые числа в заданном диапазоне [from; to], распределив работу между несколькими потоками.

Диапазон делится на блоки (по 16 блоков на поток), блоки раздаются потокам **пула потоков** (thread pool — заранее созданный набор потоков, которые берут задания из общей очереди) из стандартного модуля `std.parallelism`. Каждый поток проверяет числа своего блока **пробным делением** (делим n на числа вида 6k±1 до √n) и складывает простые в свою ячейку массива результатов — общих изменяемых данных нет, поэтому блокировки не нужны. Затем блоки склеиваются по порядку.

Мелкие блоки нужны для **балансировки нагрузки**: большие числа проверяются дольше маленьких, и если бы каждому потоку достался один большой кусок, последний поток работал бы дольше всех.

Программа выводит количество простых, первые и последние 10, время параллельного и последовательного поиска, ускорение и проверку совпадения результатов. Ускорение заметно только на больших диапазонах — на маленьких накладные расходы на потоки больше самой работы.

## Входные данные

Аргументы командной строки (все необязательные):

| Аргумент | Смысл | По умолчанию |
|---|---|---|
| `from` | начало диапазона | 1 |
| `to` | конец диапазона | 5 000 000 |
| `threads` | число потоков | число ядер |
| `out` | файл для списка простых | не записывается |

## Запуск
### Через Docker

Контейнер установит LDC, скомпилирует программу и запишет `primes.txt` в текущую папку:

```bash
docker run --rm -it \
  -v "$PWD":/app -w /app debian:bookworm-slim sh -lc \
  'apt-get update && apt-get install -y --no-install-recommends ldc build-essential && ldc2 -O primes.d && ./primes 1 5000000 4 primes.txt'
```


Нужен компилятор D: `ldc2` (`sudo apt install ldc`) или `dmd`.

```bash
ldc2 -O primes.d          # или: dmd -O primes.d
./primes 1 5000000 4 primes.txt
```
