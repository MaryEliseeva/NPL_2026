# 7. Prolog — поиск всех возможных маршрутов между двумя вершинами графа

## Постановка задачи

Дан взвешенный неориентированный граф — сеть дорог между городами с расстояниями. Нужно найти **все** маршруты между двумя заданными городами, в которых ни один город не повторяется (простые пути), и вывести их по возрастанию длины, отдельно указав кратчайший и самый длинный.

В Прологе программа — это набор **фактов** (то, что известно: `edge(A, B, 190)`) и **правил** (как выводить новое из известного). Маршрут описан двумя правилами:
- из города в него же — маршрут длины 0;
- из `Cur` в `To` можно попасть, если есть дорога `Cur → Next`, город `Next` ещё не посещён и из `Next` есть маршрут в `To`.

Пролог сам перебирает все варианты **с возвратом** (backtracking): найдя одно решение или упершись в тупик, он возвращается к последнему выбору и пробует следующий. Встроенный предикат `findall` собирает все найденные решения в список.

## Входные данные

`graph.pl` — граф в виде фактов `edge(Город1, Город2, Километры).` Дороги двусторонние, обратное направление выводит правило `connected`. Чтобы задать свой граф, достаточно отредактировать этот файл.

```prolog
edge('Санкт-Петербург', 'Великий Новгород', 190).
edge('Тверь', 'Москва', 180).
...
```

Города начала и конца передаются аргументами командной строки.

## Запуск
### Через Docker

Запускайте из папки проекта, чтобы `routes.pl` мог найти `graph.pl`:

```bash
docker run --rm -it \
  -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 \
  -v "$PWD":/app -w /app debian:bookworm-slim sh -lc \
  'apt-get update && apt-get install -y --no-install-recommends swi-prolog-nox && swipl routes.pl "Москва" "Тверь"'
```


Нужен SWI-Prolog (`sudo apt install swi-prolog`).

```bash
swipl routes.pl Москва Тверь
swipl routes.pl Санкт-Петербург Казань
swipl routes.pl "Нижний Новгород" Казань    # название с пробелом — в кавычках
```
