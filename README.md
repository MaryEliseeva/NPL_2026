# Индивидуальное задание

## 1. Многопоточность

1. **Ada** — параллельный анализ массива: поиск минимума, максимума и среднего значения.
2. **Clojure** — параллельный подсчёт количества слов в нескольких текстовых файлах.
3. **D** — параллельный поиск простых чисел в заданном диапазоне.
4. **Elixir** — параллельная обработка заказов несколькими процессами.

## 2. Алгоритмические задачи

5. **Haskell** — рекурсивный поиск количества путей в лабиринте.
6. **Lisp** — рекурсивное вычисление арифметического выражения, представленного в виде дерева.
7. **Prolog** — поиск всех возможных маршрутов между двумя вершинами графа.
8. **Scheme** — поиск наибольшей возрастающей подпоследовательности.

## 3. Ввод/вывод в консоль и файл

9. **Lua** — анализ файла с оценками студентов и формирование статистики.
10. **Perl** — консольный менеджер заметок с сохранением данных в файл.
11. **Ruby** — анализ журнала посещений из текстового файла.
12. **Swift** — консольный менеджер задач с сохранением состояния в файл.

## 4. Клиент-серверное взаимодействие

13. **Erlang** — TCP-сервер для хранения и выдачи заметок.
14. **Kotlin** — многопользовательский TCP-чат.
15. **Rust** — клиент-серверная система для выполнения статистических запросов.
16. **Zig** — клиент-серверная игра «Угадай число».

## 5. Конвертация данных

17. **F#** — конвертация CSV в HTML-таблицу.
18. **Groovy** — конвертация CSV в Markdown-таблицу.
19. **Nim** — конвертация конфигурационного текстового формата в JSON.
20. **OCaml** — конвертация JSON в CSV.
