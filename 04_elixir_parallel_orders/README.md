# 4. Elixir — параллельная обработка заказов несколькими процессами

## Постановка задачи

Есть список заказов интернет-магазина. Нужно обработать их параллельно несколькими процессами: проверить корректность, посчитать скидку, доставку и итоговую сумму, а затем вывести сводку.

Используются **процессы BEAM** — лёгкие изолированные процессы виртуальной машины Erlang/Elixir (не процессы ОС; их можно запускать тысячами). Общей памяти у них нет, они общаются только **сообщениями**: `send` кладёт сообщение в почтовый ящик процесса, `receive` достаёт его оттуда.

Схема:
- **диспетчер** — процесс, который хранит очередь заказов;
- **обработчики** (N штук) — каждый, освободившись, шлёт диспетчеру `{:ready, self()}` и получает следующий заказ или `:stop`, если заказы кончились. Такая схема «сам попросил — получил» автоматически распределяет работу: кто быстрее, тот больше обработает;
- **главный процесс** собирает результаты и печатает их по мере готовности, потом итоговый отчёт.

Правила обработки заказа:
- количество или цена ≤ 0 → заказ отклоняется;
- от 10 штук — скидка 10 %, сумма от 50 000 — ещё 5 %;
- доставка 500 руб., бесплатно от 30 000 руб.;
- обработка «занимает» 100–400 мс (имитация проверки склада и оплаты через `Process.sleep`).

В конце выводится таблица заказов, выручка по клиентам, сколько заказов взял каждый обработчик, и общее время в сравнении с последовательной обработкой.

## Входные данные

`orders.csv` — разделитель `;`, первая строка — заголовок:

```
id;client;product;qty;price
1;Иванов;Ноутбук;1;85000
2;Петрова;Мышь;12;900
```

## Запуск
### Через Docker

```bash
docker run --rm -it -v "$PWD":/app -w /app elixir:1.18 \
  elixir orders.exs orders.csv 3
```


Нужен Elixir (`sudo apt install elixir`).

```bash
elixir orders.exs orders.csv 3     # файл заказов и число обработчиков (по умолчанию orders.csv и 4)
```

## Пример вывода

```
Заказов: 12, обработчиков: 3
  [обработчик 1] заказ #1 (Иванов): 80750 руб., 193 мс
  [обработчик 2] заказ #2 (Петрова): 10220 руб., 312 мс
  ...
Выручка: 238545 руб., отклонено: 2
Заказов на обработчик: #1: 5, #2: 4, #3: 3
Время работы: 1031 мс (последовательно заняло бы ~2730 мс)
```
