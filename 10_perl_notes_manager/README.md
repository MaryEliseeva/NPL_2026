# 10. Perl — консольный менеджер заметок с сохранением в файл

## Постановка задачи

Консольная программа для ведения заметок. Каждая заметка имеет номер, дату создания, заголовок и (возможно многострочный) текст. Возможности:

| Команда | Действие |
|---|---|
| `add` | добавить заметку (заголовок и текст запрашиваются; текст заканчивается пустой строкой) |
| `list` | список заметок |
| `show N` | показать заметку N целиком |
| `edit N` | изменить заголовок и/или текст (Enter — оставить как было) |
| `delete N` | удалить заметку |
| `search слово` | поиск по заголовку и тексту без учёта регистра |
| `help`, `exit` | справка, выход |

Заметки хранятся в файле `notes.txt`, по одной на строку, поля разделены табуляцией: `номер⇥дата⇥заголовок⇥текст`. Чтобы табуляции и переводы строк внутри текста не ломали формат, они **экранируются** — заменяются на `\t` и `\n` при записи и восстанавливаются при чтении. Файл перезаписывается после каждого изменения, поэтому данные не теряются при выходе.

Программа работает в двух режимах: интерактивном (без аргументов, ввод команд в цикле) и разовом (команда передаётся аргументами — удобно для скриптов).

## Входные данные

Файл `notes.txt` создаётся автоматически при первой заметке. Другой файл можно задать переменной окружения `NOTES_FILE`.

## Запуск
### Через Docker

Контейнер остаётся интерактивным; файл заметок сохраняется в текущей папке:

```bash
docker run --rm -it -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 -v "$PWD":/app -w /app perl:5.44-bookworm perl notes.pl
```


Нужен Perl 5 (есть в любом Linux/macOS; для Windows — Strawberry Perl).

```bash
perl notes.pl                                   # интерактивный режим
perl notes.pl add "Купить продукты" "молоко, хлеб"
perl notes.pl list
perl notes.pl search хлеб
perl notes.pl delete 1
```

## Пример работы

```
Менеджер заметок. Файл: notes.txt. Введите help для справки.

Текст (пустая строка — конец):
доделать демон
запушить в репозиторий

Добавлена заметка #2
> list
#    Создана           Заголовок
1    2026-10-14 18:21  Купить продукты
2    2026-10-14 18:21  Лаба по ОС
> search ХЛЕБ
#1   Купить продукты
```
