# 18. Groovy — конвертация CSV в SQL INSERT

## Постановка задачи

Преобразовать CSV-файл (первая строка — названия столбцов) в SQL-скрипт, который создаёт таблицу (`CREATE TABLE`) и заполняет её данными (`INSERT`). Скрипт должен выполняться в СУБД без ручных правок.

Что делает программа:
- **разбирает CSV по стандарту RFC 4180**: поле в двойных кавычках может содержать запятые, переводы строк и кавычки (удвоенные: `""`). Разбор идёт **конечным автоматом** — посимвольно, с запоминанием состояния «внутри кавычек / снаружи»; поэтому простой `split(',')` здесь не подходит;
- **определяет разделитель** (`,`, `;` или табуляция) по первой строке;
- **определяет тип каждого столбца** — самый узкий тип, которому подходят все непустые значения: `BIGINT` (целое) → `DECIMAL` (дробное, допускается запятая) → `BOOLEAN` (true/false/да/нет) → `DATE` (ГГГГ-ММ-ДД) → `VARCHAR(n)`/`TEXT`;
- **экранирует строки**: одинарная кавычка внутри значения удваивается (`O'Reilly` → `'O''Reilly'`) — иначе SQL сломается, а при вставке пользовательских данных это классическая уязвимость SQL-инъекция;
- пустые значения превращает в `NULL`;
- имена таблицы и столбцов приводит к безопасному виду (нижний регистр, лишние символы → `_`) и берёт в двойные кавычки — так их нельзя спутать с ключевыми словами SQL;
- предупреждает о строках с неправильным числом полей (недостающие поля → `NULL`);
- `--batch N` объединяет до N строк в один `INSERT` (так вставка работает быстрее).

Имя таблицы по умолчанию — имя файла без расширения.

## Входные данные

`products.csv` — пример с кириллицей, запятыми, кавычками и переводом строки внутри полей, пустыми значениями:

```
id,name,category,price,in_stock,added,description
1,Ноутбук Lenovo,Электроника,85999.90,true,2026-01-15,"15.6"", 16 ГБ ОЗУ"
4,O'Reilly: Learning SQL,Книги,3200,true,2026-03-10,"Книга
на английском"
```

## Запуск
### Через Docker

Файл `products.sql` будет создан в текущей папке:

```bash
docker run --rm -it -v "$PWD":/app -w /app groovy:4.0-jdk21 \
    groovy csv2sql.groovy products.csv products.sql
```


Нужны Java и Groovy (`sdk install groovy` или `sudo apt install groovy`).

```bash
groovy csv2sql.groovy products.csv products.sql               # в файл
groovy csv2sql.groovy products.csv                            # в консоль
groovy csv2sql.groovy products.csv out.sql --table goods --batch 100
```

Проверить результат можно, например, в SQLite: `sqlite3 test.db < products.sql`.

```
  ...

    "id" BIGINT,
    "name" VARCHAR(44),

INSERT INTO "products" (...) VALUES
    (5, 'Коврик для мыши', 'Аксессуары', NULL, FALSE, '2026-03-11', 'Без цены');
```
