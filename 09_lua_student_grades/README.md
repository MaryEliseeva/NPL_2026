# 9. Lua — анализ файла с оценками студентов

## Постановка задачи

Прочитать из текстового файла оценки студентов и сформировать статистику:
- общее число записей, студентов, предметов, групп и средний балл;
- рейтинг студентов по среднему баллу со списком оценок;
- средний, минимальный и максимальный балл по каждому предмету;
- средний балл по группам;
- распределение оценок 5/4/3/2 с текстовой гистограммой;
- списки отличников (все пятёрки) и студентов с двойками.

Некорректные строки (не то число полей, оценка не число от 2 до 5) не ломают программу: они пропускаются и перечисляются в конце отчёта. Отчёт выводится в консоль и сохраняется в файл.

Данные группируются через **таблицы** Lua — единственную составную структуру языка, которая служит и массивом, и словарём (ключ → значение). Выравнивание колонок сделано через `utf8.len`: обычный `string.format` считает байты, а русская буква в кодировке UTF-8 занимает 2 байта, и столбцы бы «поехали».

## Входные данные

`grades.csv` — разделитель `;`, первая строка — заголовок:

```
student;group;subject;grade
Иванов Иван;5130201;Математика;5
Сидоров Пётр;5130201;Физика;2
```

В файл специально добавлена строка с некорректной оценкой `отл`, чтобы показать обработку ошибок.

## Запуск
### Через Docker

Отчёт `report.txt` будет сохранён в текущей папке:

```bash
docker run --rm -it -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 \
  -v "$PWD":/app -w /app nickblah/lua:5.4 \
  lua grades.lua grades.csv report.txt
```


Нужен Lua 5.3 или 5.4 (`sudo apt install lua5.4`).

```bash
lua5.4 grades.lua grades.csv report.txt    # по умолчанию grades.csv и report.txt
```
