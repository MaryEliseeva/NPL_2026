# 16. Zig — сетевая викторина

## Постановка задачи

TCP-сервер проводит викторину для подключившихся игроков:
1. спрашивает имя игрока;
2. задаёт вопросы с вариантами ответа — каждому игроку в своём случайном порядке;
3. проверяет ответ (некорректный ввод — не число или номер вне диапазона — переспрашивается), сообщает, верно ли, и называет правильный вариант;
4. в конце сообщает результат и показывает общую **таблицу рекордов** всех игроков (топ-10).

Несколько игроков играют одновременно и независимо друг от друга.

Реализация:
- сервер слушает порт (`IpAddress.listen`) и в цикле принимает подключения (`accept`);
- каждый игрок обслуживается **параллельной задачей** в группе `Io.Group` (`group.concurrent(...)`) — в стандартной реализации ввода-вывода это отдельный поток;
- таблица рекордов общая для всех задач, поэтому изменяется только под **мьютексом** (`Io.Mutex` — замок, который в каждый момент может держать только одна задача; остальные ждут);
- порядок вопросов перемешивается генератором псевдослучайных чисел, зерно которого берётся из `io.random`.

Используется только стандартная библиотека Zig.

## Входные данные

`questions.txt` — по одному вопросу на строку, поля разделены `|`, последнее поле — номер правильного варианта. Строки с `#` — комментарии, строки неверного формата пропускаются с предупреждением.

```
Какой порт по умолчанию у HTTP?|21|443|80|8080|3
```

## Запуск
### Через Docker

Команда загружает Zig 0.17 в контейнер, собирает викторину и публикует порт 9000:

```bash
docker run --rm -it -p 9000:9000 -v "$PWD":/app -w /app debian:bookworm-slim sh -lc '
  case "$(uname -m)" in aarch64|arm64) arch=aarch64;; x86_64|amd64) arch=x86_64;; *) exit 2;; esac
  apt-get update && apt-get install -y --no-install-recommends ca-certificates curl xz-utils
  mkdir -p /tmp/zig
  curl -fsSL "https://ziglang.org/download/0.17.0/zig-${arch}-linux-0.17.0.tar.xz" | tar -xJ --strip-components=1 -C /tmp/zig
  /tmp/zig/zig build-exe quiz.zig -O ReleaseSafe
  exec ./quiz 9000 questions.txt
'
```

Игроки подключаются с хоста:

```bash
nc localhost 9000
```


Нужен **Zig 0.17** (ziglang.org/download). В этой версии ввод-вывод и сеть переработаны (`std.Io`, `std.Io.net`), поэтому в Zig 0.14/0.15 код не соберётся.

```bash
zig build-exe quiz.zig -O ReleaseSafe
./quiz 9000 questions.txt       # порт и файл вопросов (по умолчанию 9000 и questions.txt)
```

Игрок подключается любым TCP-клиентом, можно из нескольких терминалов одновременно:

```bash
nc localhost 9000        # или: telnet localhost 9000
```

## Пример игры

```
Добро пожаловать в сетевую викторину! Вопросов: 6.
Как вас зовут?
> Анна

Вопрос 2/6: Какой адрес обозначает локальный компьютер?
  1) 192.168.0.1
  2) 8.8.8.8
  3) 127.0.0.1
  4) 0.0.0.0
Ваш ответ (номер): x
Введите номер варианта цифрой.
Ваш ответ (номер): 3
Верно!
...
Анна, ваш результат: 6 из 6

Таблица рекордов:
   1. Анна — 6/6
   2. Борис — 1/6
Спасибо за игру!
```

Лог сервера:

```
Викторина: загружено 6 вопросов, сервер слушает порт 9000
[+] игрок #1 подключился
[+] игрок #2 подключился
    игрок #1 назвался «Борис»
    игрок #2 назвался «Анна»
    игрок #1 «Борис»: 1/6
```
